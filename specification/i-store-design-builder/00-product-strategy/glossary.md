# Product Glossary

| Term | Meaning |
|---|---|
| Player | The person using the guided website-design experience. |
| Project | The website initiative being designed, including its purpose and audience. |
| Workspace | The application area containing missions, canvas, and contextual tools. |
| Canvas | Bounded preview of the website page currently being designed. |
| Mission | A guided task that helps the player make a meaningful design decision. |
| Level | A stage grouping one or more missions and capabilities. |
| Progression | The rules governing completion, guidance, and progressive disclosure. |
| Design identity | The shared visual language applied across the website. |
| Design token | A named reusable value such as a color, font, radius, or spacing choice. |
| Section | A meaningful region of a webpage, such as a hero, gallery, or FAQ. |
| Section variant | A curated alternative layout or presentation for a section type. |
| Component | A reusable implementation unit used to render the website. |
| Page template | A starting structure for a page with a particular purpose. |
| Shared frame | Website elements reused across pages, commonly header, navigation, and footer. |
| Responsive override | A limited device-specific adjustment that overrides a shared default. |
| Blueprint | Structured representation of pages, sections, identity, content, and responsive decisions. |
| Handoff | Delivering the blueprint and supporting assets/specifications for implementation. |
| Recommendation | Contextual guidance based on project purpose and previous choices. |
