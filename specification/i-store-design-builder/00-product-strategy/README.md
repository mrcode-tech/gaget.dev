## Strategic guardrails

1. The user chooses the business/project context; no industry is hardcoded.
2. The experience is a guided design game, not a professional-grade freeform editor.
3. The canvas is visible from the first workspace visit and evolves progressively.
4. The player makes understandable decisions using curated choices and examples.
5. The resulting website is structured, coherent, responsive, and exportable.
6. The player can revisit prior levels and revise decisions.
7. The module remains isolated from the existing GaGet shell.
