## Approved strategic guardrails

1. **User-directed design:** the user chooses components, patterns, options, and order. The product never makes creative decisions on the user's behalf.
2. **Guided, not automated:** levels, missions, explanations, and examples help users understand the decisions they are making. No AI functionality is required in the initial product.
3. **Wireframe-first:** the core output is a structured visual wireframe/design, not a finished production website or a library of supplied stock imagery.
4. **User-owned content:** users may provide content upfront or as they progress. Text can be real content or explicit placeholders; image areas are placeholders by default, with optional user-provided reference images.
5. **Flexible progression:** users can navigate forward and backward freely. Completion records progress; it does not unlock rewards or gate ordinary design freedom.
6. **Useful at every stage:** a partial project preserves the user's purpose, decisions, current structure, placeholders, and remaining work for a developer.
7. **Industry neutrality:** the project context shapes examples and understanding, never hardcoded assumptions.
8. **Isolated module:** the feature must not alter the existing GaGet shell.
