# M12 — User Stories

- **M12-US-01 Plan pages:** As a user, I want an overview of my website pages so that I can understand its structure.
- **M12-US-02 Create a page:** As a user, I want to create a blank page so that I decide what it contains.
- **M12-US-03 Use a starter:** As a user, I want to preview and explicitly choose an optional page starter so that I can begin with a useful structure.
- **M12-US-04 Manage pages:** As a user, I want to rename, reorder, duplicate, and delete pages so that I control the website structure.
- **M12-US-05 Configure routes:** As a user, I want to edit each page's route and detect conflicts so that handoff can describe intended URLs.
- **M12-US-06 Configure navigation:** As a user, I want to choose navigation labels, order, and destinations so that visitors can move through my website.
- **M12-US-07 Reuse shared elements:** As a user, I want header, navigation, footer, and identity to remain shared where intended so that the website feels consistent.
- **M12-US-08 Compose each page:** As a user, I want each page to have its own sections and responsive layout so that it serves its purpose.
- **M12-US-09 Preview the site:** As a user, I want to inspect page relationships and preview each page so that I can understand the website as a whole.
- **M12-US-10 Resolve broken links:** As a user, I want deletion to show affected links so that I can remove or retarget them deliberately.
- **M12-US-11 Stay in control:** As a user, I want page suggestions to remain optional explanations rather than automatic page creation.
