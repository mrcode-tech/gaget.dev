# M12 — Testing Strategy

## Unit

Page uniqueness, ID generation, route normalization/uniqueness, page duplication mapping, navigation resolution, deletion impact plans, shared-element references, and page ordering.

## Component

Page planner, blank/starter creation, preview confirmation, duplication summary, deletion impact dialog, navigation editor, site map, and page switching.

## Integration

Create and edit pages with M06 sections; preserve M09 identity; use M11 responsive state; ensure page duplication preserves sample versions but generates new instance IDs; verify shared element edits appear on all referenced pages.

## End-to-end

Create homepage, add two pages, configure navigation, duplicate a page, change route, resolve deletion references, and inspect all pages across three canvases.

## Accessibility

Keyboard page reordering, navigation editing, destructive confirmation, focus management, accessible labels, and relationship announcements.

## Negative

Reject duplicate routes, invalid page references, homepage deletion, duplicate IDs, unresolved deletion links, accidental shared-element duplication, and any automatic page creation.

Use synthetic projects/pages only; record implementation evidence later.
