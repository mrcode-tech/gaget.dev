# M12 — Interaction Specification

## Page planner

Present page rows/cards with title, route, type/purpose, status summary, and actions. Clearly distinguish the homepage. Offer an explicit create-page action. Do not prepopulate a mandatory sitemap.

## Create page

Ask for a page title and allow optional purpose/type and route. Offer blank page as the neutral default. Curated starters appear as selectable alternatives with preview and description. User confirms one choice before any sections are inserted.

## Duplicate page

Show what will be copied: page metadata, page-local sections, content, supported options, and responsive layout. Explain that the new page gets new page/instance IDs. Shared site elements remain shared references. Confirm before duplication.

## Delete page

Show page title/route and all known incoming internal links/navigation items. Require explicit user resolution: remove each reference or choose a replacement destination. Then request final confirmation. Homepage deletion is unavailable.

## Navigation editor

Show navigation items in current order, with label and destination. Users add, remove, rename, and reorder items explicitly. Destination selection uses existing pages and supported external/contact destinations. Invalid internal targets are not selectable.

## Page editing

Selecting a page opens its page workspace and three canvases. Page switching preserves current in-memory state. Shared elements are visually distinguished from local sections.

## Cross-page map

Provide a read-only site map/relationship view showing pages and internal links. It is not a freeform diagram editor and does not create or rearrange pages.
