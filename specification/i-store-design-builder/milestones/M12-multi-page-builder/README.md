# M12 — Multi-page Website Builder

## Strategic purpose
Expand the homepage into a complete, navigable website suited to the player's project.

## Scope
- Page planning and contextual page recommendations.
- Page templates for common purposes such as about, contact, listing, detail, FAQ, and campaign pages.
- Create, duplicate, delete, and reorder pages.
- Page-specific sections and settings.
- Shared header, navigation, footer, and identity.
- Internal links and navigation configuration.
- Multi-page preview and page completeness.

## Out of scope
A full CMS, dynamic application backend, commerce transaction engine, or arbitrary third-party integrations.

## Dependencies
M06 composition engine; M08 progression; M09 identity; M10 homepage; M11 responsive behavior.

## Acceptance criteria
Players can create relevant pages, connect them through navigation, reuse shared elements, preserve page-specific settings, and preview the website as a connected whole.

## Deliverables
Page planner, page composition workflow, navigation model, and multi-page preview.

## Definition of done
- [ ] Page lifecycle and page-type contracts documented.
- [ ] Shared and page-specific data boundaries defined.
- [ ] Navigation and internal links validated.
- [ ] Responsive behavior verified across page types.
- [ ] Acceptance and regression tests pass.
- [ ] Known limitations documented.

**Status:** Planning.
