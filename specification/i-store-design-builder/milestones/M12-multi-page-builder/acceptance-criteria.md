# M12 — Acceptance Criteria

- [ ] Every project has exactly one homepage.
- [ ] Users can create blank pages and optionally select curated starters.
- [ ] No page or starter is automatically added.
- [ ] Users can rename, reorder, duplicate, and delete non-home pages.
- [ ] Duplicate pages receive new page and component instance IDs.
- [ ] Sample references/versions and compatible content are preserved on duplication.
- [ ] Shared elements remain references and are not duplicated.
- [ ] Homepage deletion is prevented.
- [ ] Page deletion identifies and resolves every incoming internal reference.
- [ ] Navigation labels, order, visibility, and destinations are user-controlled.
- [ ] Internal links use stable page IDs.
- [ ] Duplicate routes and unresolved links are detected.
- [ ] Each page has independent desktop/tablet/mobile responsive state.
- [ ] Shared website identity and site elements render consistently.
- [ ] The site map is read-only and does not mutate project structure.
- [ ] No CMS, transaction backend, authentication, persistence, or publishing is introduced.
