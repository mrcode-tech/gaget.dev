# M15 — User Stories

- **M15-US-01 Standalone product:** As a product owner, I want the builder isolated from GaGet so that it can evolve independently.
- **M15-US-02 Account lifecycle:** As a user, I want secure account access and recovery so that I can manage my projects over time.
- **M15-US-03 Durable projects:** As a user, I want projects saved to my account so that they survive browser sessions.
- **M15-US-04 Save confidence:** As a user, I want clear save and recovery status so that I know whether my latest work is durable.
- **M15-US-05 Version history:** As a user, I want to inspect and restore earlier versions without losing the current state.
- **M15-US-06 Project management:** As a user, I want to rename, duplicate, archive, and delete projects.
- **M15-US-07 Asset lifecycle:** As a user, I want uploaded assets managed securely with clear limits and deletion controls.
- **M15-US-08 Share safely:** As a user, I want to grant and revoke read-only access to a project.
- **M15-US-09 Collaborate:** As a user, I want controlled collaboration if the product later supports multiple editors.
- **M15-US-10 Privacy:** As a user, I want to understand what data is collected and control deletion/export.
- **M15-US-11 Feedback:** As a user, I want to provide optional feedback without exposing my project content.
- **M15-US-12 Starter projects:** As a user, I want to choose a curated starter project while retaining control of every design decision.
- **M15-US-13 Reliable service:** As an operator, I want monitoring, backup, rollback, and incident procedures.
- **M15-US-14 Validated business model:** As a product owner, I want monetization considered only after evidence supports it.
