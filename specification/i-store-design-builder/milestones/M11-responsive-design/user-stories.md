# M11 — User Stories

- **M11-US-01 Preview devices:** As a user, I want to see desktop, tablet, and mobile previews simultaneously so that I can compare the same page across device classes.
- **M11-US-02 Understand inheritance:** As a user, I want to know whether a value is shared, inherited, or overridden so that I understand the effect of an edit.
- **M11-US-03 Adapt presentation:** As a user, I want curated responsive options so that I can choose how a sample adapts without using CSS.
- **M11-US-04 Reorder locally:** As a user, I want to change tablet or mobile section order independently so that the content sequence suits smaller screens.
- **M11-US-05 Hide locally:** As a user, I want to hide a section on one breakpoint without deleting it elsewhere.
- **M11-US-06 Reset override:** As a user, I want to restore a sample's responsive default so that I can undo a local adaptation.
- **M11-US-07 Review issues:** As a user, I want responsive findings linked to affected components so that I can correct overflow or readability problems.
- **M11-US-08 Preserve shared data:** As a user, I want content and sample configuration to remain synchronized so that I do not maintain duplicate content for each device.
- **M11-US-09 Respect sample capabilities:** As a user, I want controls to reflect what each sample supports so that unavailable options are not misleading.
