# M11 — Acceptance Criteria

- [ ] Three canvases remain visible simultaneously at all supported workspace widths.
- [ ] Each canvas clearly identifies its device class and simulated width.
- [ ] Preview presets are 1440px desktop, 768px tablet, and 390px mobile for repeatable verification.
- [ ] Preview widths are not treated as required CSS breakpoint thresholds.
- [ ] Shared content/configuration changes are reflected in all canvases.
- [ ] Tablet/mobile cannot independently add/remove/replace/duplicate high-level components.
- [ ] Tablet/mobile order is independently editable.
- [ ] Visibility is breakpoint-local and non-destructive.
- [ ] Only sample-declared finite responsive options are available.
- [ ] Inherited values and overrides are distinguishable and resettable.
- [ ] Unsupported overrides are rejected without fallback guessing.
- [ ] Responsive findings identify viewport and affected target.
- [ ] Validation does not silently change the project.
- [ ] Keyboard alternatives exist for drag/reorder.
- [ ] No CSS, arbitrary breakpoint, or pixel geometry editor is introduced.
- [ ] No persistence or backend is introduced.
