# M14 — Interaction Specification

## Export review screen
Present current project status, summary counts, known findings, and media availability. Explain Complete/Incomplete status and that export does not save the project online.

## Format selection
Offer Download JSON, Download Markdown, and Download ZIP package (JSON + Markdown and optionally available selected media). ZIP media inclusion is an explicit choice with clear disclosure.

## Media inclusion review
List each referenced asset with filename, type, availability, and include/exclude state. Missing session assets cannot be included and are visibly marked. Users may proceed without them.

## Download feedback
On successful local generation, show the downloaded filename and format. On failure, explain what failed and which alternative formats remain available. Never claim the project is saved to an account/cloud.

## Partial project language
Use "Incomplete handoff" and explain remaining work. Do not block export because of warnings or unfinished missions.
