# M14 — User Stories

- **M14-US-01 Export anytime:** As a user, I want to export an incomplete project so that I can share progress before finishing.
- **M14-US-02 Get JSON:** As a user/developer, I want a versioned JSON blueprint so that the design can be inspected programmatically.
- **M14-US-03 Get Markdown:** As a user/developer, I want a readable handoff so that the website intent and structure are understandable.
- **M14-US-04 Include media:** As a user, I want an optional package of selected available images so that the handoff contains the assets I chose.
- **M14-US-05 Understand omissions:** As a user, I want unavailable or excluded media clearly listed so that no one assumes it was included.
- **M14-US-06 Understand status:** As a user, I want the export to state Complete or Incomplete so that recipients know what remains.
- **M14-US-07 Preserve decisions:** As a user, I want sample versions, identity, responsive settings, and content states preserved so that the handoff accurately reflects my choices.
- **M14-US-08 Export privately:** As a user, I want export generated locally so that my project is not uploaded to a service.
- **M14-US-09 Avoid accidental changes:** As a user, I want export not to mutate my project or mark work complete.
- **M14-US-10 Understand limitations:** As a developer, I want the package to identify design-only decisions and excluded production behavior so that I do not mistake a blueprint for an implemented website.
