# M08 — Game Progression and Guided Learning

## Strategic purpose

Connect the designed journey to working application state and feedback.

## Objective

Implement missions, progress transitions, unlocking, help, and revision behavior.

## Scope

- Mission runtime
- level state
- prerequisites
- completion evaluation
- unlock rules
- progress persistence
- hints
- tutorials
- achievements
- optional challenges
- checkpoints
- revisiting
- undo/redo integration.

## Out of scope

Competitive leaderboards, timers, punitive scoring, or social gamification.

## Dependencies

M01, M04–M06.

## Acceptance criteria

A player can complete the defined journey, see meaningful progress, revisit completed work, and resume after leaving without losing state.

## Deliverables

Playable progression system.
