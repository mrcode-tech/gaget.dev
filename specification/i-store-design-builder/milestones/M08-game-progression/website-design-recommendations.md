# Website Design Direction and Structure Guidance

## Purpose

Define how the product may help users understand an overall website structure, with particular relevance to the first store-focused journey, without taking creative decisions away from them.

## Guidance type

The product may provide general, curated, explanatory website-structure examples. For example, a store-oriented illustrative sequence might include:
- Header and navigation.
- Store introduction or hero.
- Product categories.
- Featured products.
- Trust information or testimonials.
- Promotional or informational sections.
- Footer and supporting links.

This is an example of a possible structure, not a required template or a claim that every store needs every section.

## User agency

- Present structure guidance as optional information.
- Explain the purpose of sections and possible relationships.
- Let users decide whether a section is relevant.
- Users explicitly choose component types, samples, and ordering.
- Users may omit irrelevant sections where the journey supports Not needed or simply choose not to add them.
- Users may depart from the example and create a different structure.

## Recommendation boundary

This guidance is about an overall design direction or illustrative section sequence. It is not permission to:
- Automatically select or rank individual component samples.
- Automatically insert, replace, or arrange components.
- Create a personalized automatic design recommendation engine.
- Generate website designs or content using AI in the initial product.

These restrictions preserve M00/M01/M03/M07. The first store-focused journey may include authored reference structures and examples, but the product remains generic and user-directed.

## Relationship to M07

M07 owns component taxonomy, sample metadata, visual previews, and sample-level selection guidance. This M08 document owns how high-level structure guidance supports the journey. Neither milestone silently chooses the user's components.

## Acceptance criteria

- [ ] General structure examples are optional and explanatory.
- [ ] Store examples support the first journey without hardcoding the product to stores.
- [ ] Users decide which sections/components to use and their order.
- [ ] No automatic sample recommendation, selection, insertion, replacement, or arrangement is introduced.
- [ ] No AI-generated recommendation capability is added to the initial product.
