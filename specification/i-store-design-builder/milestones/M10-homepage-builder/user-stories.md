# M10 — User Stories

- **M10-US-01 Discover sections:** As a user, I want to browse homepage section families so that I can understand the kinds of content a homepage can contain.
- **M10-US-02 Compare samples:** As a user, I want to compare distinct samples within a section type so that I can choose the presentation I prefer.
- **M10-US-03 Preview in context:** As a user, I want to preview a sample in isolation and within my page so that I can judge its fit before insertion.
- **M10-US-04 Insert deliberately:** As a user, I want to confirm a sample and choose its insertion position so that my page changes only when I request it.
- **M10-US-05 Configure content:** As a user, I want to edit supported text, labels, links, item data, and image slots so that the section communicates my actual offering.
- **M10-US-06 Keep placeholders:** As a user, I want to leave draft or placeholder content where necessary so that I can continue composing before content is ready.
- **M10-US-07 Arrange sections:** As a user, I want to reorder, duplicate, replace, and remove sections so that I control my page structure.
- **M10-US-08 Understand relevance:** As a user, I want optional explanations of a section's purpose so that I can decide whether it is relevant.
- **M10-US-09 Define visitor action:** As a user, I want to identify the primary action I want visitors to take so that the homepage communicates a clear next step.
- **M10-US-10 Preview responsively:** As a user, I want to see the homepage in desktop, tablet, and mobile canvases so that I understand its current composition.
- **M10-US-11 Preserve identity:** As a user, I want compatible sections to use my active website identity without losing their sample-specific character.
- **M10-US-12 Preserve genericity:** As a user with a non-store website, I want the same section system to support my purpose without store-only assumptions.
- **M10-US-13 Shared frame:** As a user, I want shared header/navigation/footer elements to remain consistent rather than accidentally creating duplicate site-wide elements.
- **M10-US-14 Actionable findings:** As a user, I want structural/content issues linked to the relevant section so that I can address them myself.
