# M10 — Objectives and Scope

## Problem

A generic canvas and component catalogue do not by themselves help a user decide how to compose a useful homepage. M10 turns the existing M06 composition engine and M07 portfolio into a complete, purposeful homepage workflow.

## Goals

- Provide a discoverable library of homepage section types and samples.
- Let users compose a homepage using explicit sample selection and high-level ordering.
- Make the relationship between project purpose, visitor needs, and section roles understandable.
- Support a clear primary visitor action selected by the user.
- Preserve meaningful sample diversity and apply M09 identity tokens only where supported.
- Keep missing content and media non-blocking through placeholders.
- Provide an immediately understandable desktop/tablet/mobile representation under existing M01/M06 rules.

## Non-goals

- A mandatory or automatically generated homepage structure.
- AI recommendations, automatic section selection, ranking, insertion, replacement, or ordering.
- A full-page template marketplace.
- Specialized store checkout, payments, booking, membership, or other business backends.
- Detailed visual editing, arbitrary styling, CSS, pixel geometry, or nested layout editing.
- Multi-page planning/navigation ownership (M12).
- Detailed breakpoint authoring beyond M06 (M11).
- Content management, asset library, upload lifecycle, and quality audit (M13).
- Persistence, autosave, undo/redo, history, authentication, or cloud storage.
- Export/handoff implementation (M14).

## Homepage success

A user can produce a coherent homepage by choosing relevant sections, selecting distinct samples, entering or deferring supported content, arranging sections, and identifying the intended visitor action. Coherence is evaluated through objective structure and content readiness checks, not an aesthetic score.

## Initial scope

- Homepage section taxonomy and discovery.
- Section sample browsing, preview, comparison, and insertion.
- Section-level configuration using sample-defined fields/options.
- Reorder, duplicate, replace, and remove via M06 commands.
- Project purpose and visitor intent shown as contextual guidance.
- Primary and optional secondary action slots.
- Shared header/navigation/footer semantics.
- Placeholder content and media intent.
- Three-canvas preview and M09 identity integration.
- Homepage structure validation and basic completeness feedback.

## Deferred

Specialized page templates, multi-page navigation, advanced responsive rules, asset processing, SEO authoring, publishing, production code, and persistence remain outside M10.
