# M09 — Visual Identity Builder

## Strategic purpose

Let players establish a reusable visual language through approachable choices.

## Objective

Build the player-facing identity missions and apply selected tokens globally.

## Scope

- Mood/personality
- palette selection
- typography pairing
- image direction
- button/form styles
- global tokens
- preview
- theme presets
- consistency and contrast guidance.

## Out of scope

Advanced brand import, exhaustive token editors, and arbitrary CSS.

## Dependencies

M06–M08.

## Acceptance criteria

Identity choices apply consistently to rendered pages and can be revised centrally; choices are understandable without specialist terminology.

## Deliverables

Working identity builder and website token model.
