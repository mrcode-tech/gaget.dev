# M09 — User Stories

## Identity discovery

- **M09-US-01 — Explore directions:** As a website creator, I want to browse curated visual directions so that I can understand possible visual personalities before choosing one.
- **M09-US-02 — Compare directions:** As a website creator, I want to inspect representative previews of directions so that I can compare their visual character.
- **M09-US-03 — Combine aspects:** As a website creator, I want to explicitly combine supported aspects of different directions so that my identity reflects my own choices.
- **M09-US-04 — Revisit decisions:** As a website creator, I want to revisit identity stages so that I can refine my choices as the website develops.

## Colors and typography

- **M09-US-05 — Select a palette:** As a website creator, I want to preview curated palettes on representative content so that I can choose a coherent color foundation.
- **M09-US-06 — Understand color roles:** As a website creator, I want semantic color-role names and explanations so that I understand where each color is used.
- **M09-US-07 — Adjust supported colors:** As a website creator, I want to adjust supported palette values and see contrast feedback so that I can make informed choices.
- **M09-US-08 — Select typography:** As a website creator, I want to compare curated font pairings and type hierarchies so that I can choose readable typography without configuring every text element.
- **M09-US-09 — Preview text roles:** As a website creator, I want to see headings, body text, labels, and captions together so that I can judge the hierarchy.

## Imagery and shared styles

- **M09-US-10 — Define image direction:** As a website creator, I want to describe the intended photography or illustration style so that supplied assets and placeholders have a coherent direction.
- **M09-US-11 — Choose shared styles:** As a website creator, I want to select supported button and form styles so that compatible components share a recognizable visual language.
- **M09-US-12 — Choose spacing conventions:** As a website creator, I want curated spacing and layout presets so that compatible components use coherent spacing relationships.

## Preview, application, and review

- **M09-US-13 — Preview before applying:** As a website creator, I want identity changes previewed on representative samples and all responsive canvases so that I can review their effect before confirmation.
- **M09-US-14 — Confirm identity:** As a website creator, I want to confirm a reviewed identity so that it becomes the active visual foundation of my project.
- **M09-US-15 — Preserve my work:** As a website creator, I want identity application to preserve component structure, content, and responsive arrangements so that visual refinement does not destroy my composition.
- **M09-US-16 — Understand compatibility:** As a website creator, I want to know which component samples support each identity choice so that I understand why some components may retain sample-specific styling.
- **M09-US-17 — Review consistency:** As a website creator, I want clear feedback about color, typography, contrast, shared styles, and responsive presentation so that I can decide what to improve.
- **M09-US-18 — Revise active identity:** As a website creator, I want to revise my active identity through a draft and confirmation so that I can improve it without partially changing the live project during exploration.

## Product and catalogue responsibilities

- **M09-US-19 — Author compatibility:** As a product/design author, I want each sample to declare supported identity slots and mappings so that identity application is deterministic and bounded.
- **M09-US-20 — Preserve diversity:** As a product/design author, I want identity tokens to map to compatible presentation roles without flattening sample-specific layouts and character.
- **M09-US-21 — Maintain accessible palettes:** As a product/design author, I want curated palettes and combinations reviewed against WCAG 2.2 AA so that the catalogue communicates known contrast limitations.
- **M09-US-22 — Maintain generic coverage:** As a product/design author, I want identity directions and examples to support multiple website purposes so that the product is not store-specific.

## Out of scope stories

The initial product does not support arbitrary CSS editing, AI-generated identities/assets, stock-image search, automatic component recommendations or composition, multiple saved identity alternatives, or persistent identity storage.
