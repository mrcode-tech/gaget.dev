# Initial Portfolio Plan

## Purpose

Translate the approved M07 scope into a practical first portfolio without confusing a complete taxonomy with complete sample coverage.

## Approved delivery strategy

- Define the full generic taxonomy early.
- Deliver a substantial, usable initial sample set across all major categories.
- Prioritize the first complete store-design journey.
- Include foundational generic component types that are useful across website purposes.
- Expand samples progressively according to user-journey coverage and identified portfolio gaps.
- Require every published sample to satisfy the M03/M07 design, responsive, accessibility, content-contract, and preview standards.

## Initial coverage principle

M07 does not require every category/subcategory to contain a sample at first release, nor does it require every component type to have multiple samples immediately.

The first portfolio must be useful enough to support the primary journey and demonstrate that the library is not a store-only collection. Priority component types should have meaningful alternatives rather than superficial color variations.

## Priority groups

### Priority 1 — First store-focused journey

Establish samples for the component types needed to compose a coherent store website, including:
- Header and primary navigation.
- Hero / homepage introduction.
- Product category presentation.
- Product grid or list.
- Featured product or promotion.
- Store benefits / trust information.
- Testimonials or reviews where relevant.
- FAQ or supporting information.
- Calls to action.
- Footer and contact information.

The exact page composition remains user-directed; this list is a portfolio coverage guide, not a mandatory website template.

### Priority 2 — Foundational generic components

Ensure the initial catalogue also includes reusable components for:
- Professional services.
- Personal portfolios and creators.
- Editorial/publication content.
- Organizations and non-profits.
- General business and community websites.

Examples include image-text content, service cards, portfolio galleries, team, about, process, statistics, contact, newsletter, and general page introductions.

### Priority 3 — Progressive breadth and depth

Expand:
- Additional component types and subcategories.
- More meaningful samples per high-priority type.
- Visual-style diversity.
- Website-purpose coverage.
- Advanced but still bounded sample-specific options.
- Additional responsive presentation approaches.

## Sample selection priorities

Prioritize sample authoring by:
1. Coverage of the first complete journey.
2. Reuse across different website purposes.
3. Importance of the visitor task served.
4. Meaningful design diversity within a component type.
5. Responsive and accessibility quality.
6. Gaps revealed by catalogue review.

These are portfolio planning criteria, not a user-facing ranking of samples.

## Release readiness

A sample is included in the published portfolio only after it passes the M07 quality-governance process and has:
- Stable ID/version and taxonomy classification.
- Design rationale and concise description.
- Supported content schema and finite options.
- Purpose-aware placeholders.
- Desktop/tablet/mobile presentations.
- Isolated and contextual previews as appropriate.
- Synthetic representative content.
- Review evidence and lifecycle metadata.

## Tracking coverage

Track taxonomy coverage separately from published sample coverage. For each component type, record whether it is:
- Defined in taxonomy.
- Planned for a future portfolio increment.
- In authoring/review.
- Published with one or more samples.

Do not represent an empty but defined component type as having available samples. Do not set arbitrary quantity targets as a substitute for quality and journey coverage.

## Acceptance criteria

- [ ] Full generic taxonomy is defined.
- [ ] Initial samples cover major categories sufficiently for a usable first portfolio.
- [ ] Store-focused journey receives first priority.
- [ ] Foundational non-store component coverage is included.
- [ ] Sample depth expands progressively.
- [ ] Taxonomy and sample availability are reported separately.
- [ ] Published samples meet the quality and responsive requirements.
