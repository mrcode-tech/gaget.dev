# M13 — User Stories

- **M13-US-01 Edit fields:** As a user, I want to edit supported content fields so that my website reflects my own information.
- **M13-US-02 Track readiness:** As a user, I want to mark content final, draft, placeholder, or missing so that handoff communicates its status.
- **M13-US-03 Describe media:** As a user, I want to describe the purpose of an image slot so that I know what asset belongs there.
- **M13-US-04 Attach my image:** As a user, I want to select my own local image for the current session so that I can preview it in my design.
- **M13-US-05 Reuse media:** As a user, I want to explicitly reuse a selected image in another slot so that I control asset placement.
- **M13-US-06 Add alt text:** As a user, I want to describe informative images so that the design communicates their meaning accessibly.
- **M13-US-07 Validate links:** As a user, I want broken or invalid links identified so that I can correct them.
- **M13-US-08 Review issues:** As a user, I want findings linked to their exact fields so that I can address issues efficiently.
- **M13-US-09 Understand readiness:** As a user, I want to see blocking errors, warnings, and informational notes so that I understand handoff readiness.
- **M13-US-10 Preserve control:** As a user, I want the product to report issues without silently rewriting my content or changing my media choices.
- **M13-US-11 Understand media limits:** As a user, I want to know that unexported local media may be lost when my session ends so that I can prepare my handoff.
