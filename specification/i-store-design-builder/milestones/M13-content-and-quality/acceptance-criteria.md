# M13 — Acceptance Criteria

- [ ] Content controls are generated only from sample-defined schemas.
- [ ] Content can be marked final, draft, placeholder, or missing.
- [ ] Placeholder purpose is captured where applicable.
- [ ] Users can select supported local image files for the active session.
- [ ] File type/size/dimension checks are applied using documented limits.
- [ ] No file upload, backend asset library, or browser persistence occurs.
- [ ] Project JSON stores metadata and session asset IDs, not raw file objects.
- [ ] Users explicitly attach/reuse/replace/remove image references.
- [ ] Informative images support user-authored alt text; decorative images are classified.
- [ ] Only sample-supported image presentation controls are exposed.
- [ ] Required fields, links, routes, missing assets, and accessibility issues are validated.
- [ ] M09 contrast and M11 responsive findings are aggregated without duplicate ownership.
- [ ] Findings identify exact correction targets and severity.
- [ ] Readiness summary is not a subjective score.
- [ ] No automatic copy rewrite, media selection, alt-text generation, or page restructuring occurs.
- [ ] Media/session loss limitations are clearly communicated.
- [ ] M14 export can package explicitly selected available media or report unavailable assets.
