## Source of truth

The existing application repository is authoritative. Figma may be used as a complementary exploration/review workspace but does not replace repository documentation or implementation tokens.

## M03 baseline

The approved direction is a distinctive professional creative-workspace identity: neutral foundation, restrained semantic colors, a recognizable brand accent, light and dark themes, functional sans-serif typography with clear hierarchy, balanced density, and subtle purposeful motion. Avoid generic GPT/AI-dashboard styling and unnecessary decoration. Keep the website canvas and sample previews visually central.

See [M03 Visual Identity](../milestones/M03-visual-design-system/visual-identity.md), [Design Tokens](../milestones/M03-visual-design-system/design-tokens.md), and [Builder Interface Specification](../milestones/M03-visual-design-system/builder-interface-specification.md).
