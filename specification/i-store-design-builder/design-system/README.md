# Design System Documentation

This folder describes the **Design Builder application's own UI system**. It is distinct from the website identity and design tokens players create.

Planned documents: `product-ui-foundations.md`, `color-and-theme-tokens.md`, `typography.md`, `spacing-and-layout.md`, `components-and-patterns.md`, `iconography-and-illustration.md`, `motion-and-feedback.md`, and `accessibility.md`.

Do not conflate the editor's visual language with the player-created website identity specified in M09.
