# Product and Architecture Decisions

Record significant cross-milestone decisions here. Each record should include context, decision/status, alternatives, rationale, consequences, date, and affected milestones.

Use sequential identifiers, e.g. `ADR-0001-module-boundary.md` or `PDR-0001-canvas-visible-from-start.md`.

Approved principles:
- Canvas visible from the beginning and progressively takes shape.
- Product adapts to the player's project; no industry is hardcoded.
- Completed levels can be revisited and revised.
- Guided, bounded editing rather than unrestricted freeform design.
- Feature remains isolated from the existing GaGet shell.

- [ADR-0001 — Lightweight session-based MVP with explicit export](ADR-0001-lightweight-session-mvp.md): accepted MVP C release boundary; supersedes conflicting persistence/history requirements for the first release.
