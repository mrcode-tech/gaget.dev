# Target Wireframes — Developer Tools Expansion

**Status:** Proposed layouts, not approved designs or evidence of current browser behavior. Markdown wireframes describe layout/behavior; create editable SVG and PNG target assets later where greater visual precision is needed.

Reuse the existing shell and ToolLayout. Use current breakpoints: XS <640px, SM 640–767px, MD 768–1023px, LG 1024–1279px, XL 1280–1535px, 2XL ≥1536px. Define scroll ownership, keep controls reachable on short-height viewports and zoom, and verify RTL. Use existing Input, Textarea, Button, Select, Card and ScrollArea where suitable.

- [Workspace layouts](./workspace-layouts.md) — category patterns and responsive behavior.
- [File input](./file-input.md) — file-only and mixed-input patterns.
- [Developer Tool Workbench](./developer-tool-workbench.md) — current text-first input/output layout for standalone developer tools.
- [Encoding Workbench](./encoding-workbench.md) — one operation selector for common text encodings and representations.
